# Module 4: Organize and Protect Data
## Secure Data

| Concept                     | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Data Security**           | - Protecting data from unauthorized access or corruption by adopting safety measures                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Google Sheets vs Excel**  | - **Both** have features that let you protect your spreadsheets or parts of your spreadsheets from being edited, from the entire worksheet down to single cells in a table<br>&emsp;• You can lock formulas so they aren’t accidentally broken<br>    <br>- **Both** have access control features<br>&emsp;• In Excel, you can encrypt files and worksheets with passwords before emailing them<br>&emsp;• In Google Sheets, the sharing menu allows you to control who can see or edit the sheet online<br>    <br>- **Both** can let you hide and unhide tabs and sheets, but tabs can be unhidden by someone else |
| **Encryption**              | - Uses a unique algorithm to alter data and make it unusable by users and applications that don’t know the algorithm<br>- The algorithm is saved as a key which can be used to reverse the encryption<br>&emsp;• If you have the key, you can use the data in its original form                                                                                                                                                                                                                                                                                                                                      |
| **Tokenization**            | - Replaces data elements you want to protect with randomly generated data referred to as a **token**<br>- The original data is stored in a separate location and mapped to the tokens<br>- To access the complete original data, the user or application needs to have permission to use the tokenized data and the token mapping<br>- ***Even if the tokenized data is hacked, the original data is safe and secure in a separate location***                                                                                                                                                                       |
| **Version Control**         | - Enables all collaborators within a file to track changes over time<br><br>- You can understand who made what changes to a file, when they were made, and why                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Data Privacy and Kaggle** | - You can set your uploaded datasets to private<br>&emsp;• If you make them public, **you will not be able to make them private again**<br>&emsp;• The only option would be to delete datasets you wish to make private again                                                                                                                                                                                                                                                                                                                                                                                        |

## Summary

I'm a big proponent of privacy, collaboration, and version control features in any system! If you are working on a group project, public dataset solutions, and more, this would be immensely helpful so you don't lose data. Version control is a great way to back up your files because there is always a chance changing things breaks something, and then you have something to compare your files to.

  

Data security involves adopting safety measures in order to protect data from unauthorized access or corruption. Encryption uses a unique algorithm to alter data and make it inaccessible without the algorithm. When using tokenization as a safety measure, the data elements to be protected are replaced as a randomly generated token. Version control enables all collaborators within a file to track changes, such as who made what edits to the file, when they were made, and why.

  

Metadata can be used to understand file-naming conventions and how they’re structured, even in old projects.
