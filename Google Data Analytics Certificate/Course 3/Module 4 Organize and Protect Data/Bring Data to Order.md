## Summary

Naming conventions are guidelines that describe the content, date, or version of a file. Foldering is the act of creating folders for organizing files. The key goals of foldering include keeping project-related files together and organizing them into subfolders. The process of structuring folders broadly at the top, then breaking down those folders into more specific topics, is creating a hierarchy. ProjectName_YYYY_MM_DD_V01 is an effective file name because it is an appropriate length and it references the project name, creation date, and version. In an effective hierarchy, subfolders are stored within broader-topic folders in order to help organize files into categories.
