## Summary

Data is considered reliable when it is accurate, complete, and unbiased information that has been vetted and proven fit for use. Vetted public datasets, academic papers, and governmental agency data are usually good data sources. To determine if a data source is cited, ask three questions: 

1. Is this dataset from a credible organization? 
2. Who created this dataset? 
3. And when was this data last refreshed?

They have considered whether the data is current. Current data is timely and relevant.
