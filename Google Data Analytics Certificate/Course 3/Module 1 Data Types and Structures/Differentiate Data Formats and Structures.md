# Module 1: Data Types and Structures

## Differentiate Data Formats and Structures

| Concept                               | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Qualitative Data**                  | - Usually listed as a name, category, or description<br><br>- **Examples:**<br>&emsp;• Favorite exercise activity<br>&emsp;• Brand with best customer service<br>&emsp;• Fashion preferences of young adults                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Quantitative Data**                 | - Can be measured or ​counted and then expressed as a number <br>&emsp;• Break it down into discrete or continuous data<br><br>- **Examples:**<br>&emsp;• Percentage of board certified doctors who are women<br>&emsp;• Population size of elephants in Africa<br>&emsp;• Distance from Earth to Mars at a particular time                                                                                                                                                                                                                                                                                           |
| **Discrete Data**                     | - Data that is counted and has a limited number of value<br>&emsp;• Discrete data isn't limited to dollar amounts<br><br>- **Examples:**<br>&emsp;• Examples of other discrete data are stars and points<br>&emsp;&emsp;• When partial measurements (half-stars or quarter-points) aren't allowed, the data is discrete<br>&emsp;&emsp;• If you don't accept anything other than full stars or points, the data is considered discrete<br><br>&emsp;• Number of people who visit a hospital on a daily basis (10, 20, 200)<br>&emsp;• Maximum capacity allowed in a room<br>&emsp;• Tickets sold in the current month |
| **Continuous Data**                   | - Data that is measured and can have almost any numeric value<br><br>- **Examples:**<br>&emsp;• Height of kids in third grade classes (52.5 inches, 65.7 inches)<br>&emsp;• Runtime markers in a video<br>&emsp;• Temperature<br>&emsp;• Duration of a customer service call                                                                                                                                                                                                                                                                                                                                          |
| **Nominal Data**                      | - A type of ​qualitative data that's categorized without a set order <br>&emsp;• This data doesn't have a sequence<br><br>- **Examples:**<br>&emsp;• First time customer, returning customer, regular customer<br>&emsp;• New job applicant, existing applicant, internal applicant<br>&emsp;• New listing, reduced price listing, foreclosure                                                                                                                                                                                                                                                                        |
| **Ordinal Data**                      | - A type of qualitative data with a set order or scale<br><br>- **Examples:**<br>&emsp;• Movie ratings (number of stars: 1 star, 2 stars, 3 stars)<br>&emsp;• Ranked-choice voting selections (1st, 2nd, 3rd)<br>&emsp;• Satisfaction level measured in a survey (satisfied, neutral, dissatisfied)                                                                                                                                                                                                                                                                                                                   |
| **Internal Data**                     | - Data that lives within a company's own systems<br><br>- **Examples:**<br>&emsp;• Wages of employees across different business units tracked by HR<br>&emsp;• Sales data by store location<br>&emsp;• Product inventory levels across distribution centers                                                                                                                                                                                                                                                                                                                                                           |
| **External Data**                     | - Data that lives and is generated outside of an organization <br>&emsp;• Becomes particularly valuable when ​your analysis depends on as many sources as possible<br><br>- **Examples:**<br>&emsp;• National average wages for the various positions throughout your organization<br>&emsp;• Credit reports for customers of an auto dealership                                                                                                                                                                                                                                                                      |
| **Structured Data**                   | - Data organized in a certain format such as rows and columns<br>&emsp;• This makes it easier to search and analyze<br><br>- **Examples:**<br>&emsp;• Expense reports<br>&emsp;• Tax returns<br>&emsp;• Store inventory<br><br>- **Sources of Structured Data**<br>&emsp;• Spreadsheets<br>&emsp;• Library catalogs<br>&emsp;• Databases that store datasets                                                                                                                                                                                                                                                          |
| **Unstructured Data**                 | - Data that is not organized in any easily identifiable manner <br>&emsp;• For example, audio and video files because there's no clear way to identify or organize their content<br>&emsp;• The data doesn't fit neatly into rows and columns like structured data<br><br>- **Examples:**<br>&emsp;• Social media posts<br>&emsp;• Emails<br>&emsp;• Videos<br>&emsp;• Audio files<br>&emsp;• Photos                                                                                                                                                                                                                  |
| **Primary Data**                      | - Collected by a researcher from first-hand sources <br><br>- **Examples:**<br>&emsp;• Data from an interview you conducted<br>&emsp;&emsp;• Data from a survey returned from 20 participants<br>&emsp;• Data from questionnaires you got back from a group of workers                                                                                                                                                                                                                                                                                                                                                |
| **Secondary Data**                    | - Gathered by other people or from other research<br><br>- **Examples:**<br>&emsp;• Data you bought from a local data analytics firm’s customer profiles<br>&emsp;• Demographic data collected by a university<br>&emsp;• Census data gathered by the federal government                                                                                                                                                                                                                                                                                                                                              |
| **Data Model**                        | - A model that is used for ​organizing data elements and how they relate to one another                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Data Elements**                     | - Pieces of information<br><br>- **Examples:**<br>&emsp;• Names<br>&emsp;• Account numbers<br>&emsp;• Addresses                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Data Modeling**                     | - The process of creating diagrams that visually represent how data is organized and structured <br>- Made of three main levels<br>&emsp;• Conceptual<br>&emsp;• Logical<br>&emsp;• Physical<br><br>[Comparison of Data Models](https://www.1keydata.com/datawarehousing/data-modeling-levels.html "comparison of data models")                                                                                                                                                                                                                                                                                       |
| **Conceptual Data Modeling**          | - Gives a high-level view of the data structure, such as how data interacts across an organization<br>- May be used to define the business requirements for a new database<br>- Doesn't contain technical details.                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Logical Data Modeling**             | - Focuses on the technical details of a database such as relationships, attributes, and entities<br>- Defines how individual records are uniquely identified in a database<br>- Doesn't spell out actual names of database tables<br>&emsp;• That's the job of a physical data model                                                                                                                                                                                                                                                                                                                                  |
| **Physical Data Modeling**            | - Depicts how a database operates<br>- Defines all entities and attributes used<br>&emsp;• Includes table names, column names, and data types for the database                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Data-Modeling Techniques**          | - Two common methods <br>&emsp;• Entity Relationship Diagram (ERD)<br>&emsp;• Unified Modeling Language (UML)<br><br>- In practice, you'll be using your organization's existing technique                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Entity Relationship Diagram (ERD)** | - A visual way to understand the relationship between entities in the data model                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Unified Modeling Language (UML)**   | - Very detailed diagrams that describe the structure of a system by showing the system's entities, attributes, operations, and their relationships                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## Summary

Ordinal data is a type of qualitative data with a set order or scale. For example, the number of stars to represent how much a person liked a movie. Discrete data is data that is counted and has a limited number of values, for example, ensuring users can't choose 4.5 stars because they must choose 4 or 5 stars, not partial values. The number of points scored in a basketball game is an example of discrete data.

Continuous data is measured and can have almost any numeric value. For example, the height of a skyscraper. In data analytics, external data is generated from, and lives, outside of an organization. Unstructured data is not organized in any easily identifiable manner, although it may have an internal structure. A data model is used to organize data elements and how they relate to one another. Data elements are pieces of information, such as people’s names, account numbers, and addresses. To collect nominal qualitative data, a data analyst could ask a question such as "What is your job title?".
