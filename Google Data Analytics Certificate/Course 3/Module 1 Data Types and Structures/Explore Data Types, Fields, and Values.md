## Summary

In a data table, the columns are fields, and the rows are records. A data type is a specific kind of data attribute that tells what kind of value the data is. Text, or string, data types are sequences of characters and punctuation that contain textual information. When using long data, each subject has data in multiple rows. This is because each row represents one observation point per subject.
