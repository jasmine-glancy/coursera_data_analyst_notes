# Module 3: Database Essentials

## Work With Datasets

| Concept                 | Notes                                                                                                                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Databases**           | - A collection of data stored in a computer system                                                                                                                                                                                                      |
| **Metadata**            | - Data about data<br>- Extremely important when working with databases; think reference guide<br>- Tells you where the data comes from, when and how it was created, and what it’s all about                                                            |
| **Relational database** | - A database that contains a series of related tables that can be connected via their relationships <br>- For two tables to have a relationship, one or more of the same fields must exist inside both tables                                           |
| **Primary Key**         | - An identifier that references a column in which each value is unique<br>- Cannot be NULL or blank<br>- One primary key per table                                                                                                                      |
| **Foreign Key**         | - A field within a table that’s a primary key in another table <br>- Connects one table to another<br>- More than one key can exist in a table                                                                                                          |
| **Normalization**       | - The process of organizing data in a relational database<br>- For example, creating tables and establishing relationships between those tables<br>- Applied to eliminate data redundancy, increase data integrity, and reduce complexity in a database |
| **Composite Key**       | - A primary key constructed using multiple columns of a table                                                                                                                                                                                           |

## Summary

A relational database contains a series of tables that can be connected to form relationships.

A primary key is an identifier that references a database column with a unique key. If you create a database table with a primary key, it must be unique and its value must not be null or blank. Data professionals use normalization to eliminate data redundancy, increase data integrity, and reduce complexity in a database. Normalization is the process of organizing data in a relational database. When using a relational database, data analysts write queries to request data from the related tables.
