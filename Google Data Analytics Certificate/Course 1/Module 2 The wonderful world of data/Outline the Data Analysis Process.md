# Module 2: The Wonderful World of Data

## Outline the Data Analysis Process

| Concept          | Notes                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ask Phase**    | - We define the problem to be solved<br>- Make sure you fully understand stakeholder expectations<br>- **Step 1:** Determine who the stakeholders are<br>- **Step 2:** Develop strong communication skills<br>- Take the time to fully understand expectations<br>- **Define the problem to be solved**<br>- Decides which questions to answer in order to solve the problem |
| **Stakeholders** | - Hold a stake in the project. <br>- They're people who have invested time and resources into a project and are interested in the outcome.                                                                                                                                                                                                                                   |
| **Prepare**      | - The emphasis is on identifying and locating data you can use to answer your questions                                                                                                                                                                                                                                                                                      |
| **Process**      | - ***Refine the data***<br>- Eliminate any errors and inaccuracies <br>- Clean and transform data into a more usable format<br>- Combine two or more datasets to make information more complete<br>- Remove outliers which can skew the information                                                                                                                          |
| **Analyze**      | - Use tools to transform and organize information so you can draw useful conclusions, make predictions, and drive informed decision making<br>- Uses many tools                                                                                                                                                                                                              |
| **Share**        | - Share what you've learned with the stakeholders!<br>- Helps stakeholders make effective, data-driven decisions                                                                                                                                                                                                                                                             |
| **Act**          | - The business takes all ​of the insights you, the data analyst, have provided ​and puts them to work in order ​to solve the original business problem.                                                                                                                                                                                                                      |

## Summary

The ask phase involves defining the problem to be solved and confirming understanding of expectations. Stakeholders are the people who invest time and resources into a project and are interested in its outcome. During the process step, data analysts may remove outliers, which are data points that lie significantly outside the overall pattern of data. These are removed because they can potentially skew the information. In the share phase of the [[Outline the Data Analysis Process]], we create visuals to help people understand complex facts and figures.
