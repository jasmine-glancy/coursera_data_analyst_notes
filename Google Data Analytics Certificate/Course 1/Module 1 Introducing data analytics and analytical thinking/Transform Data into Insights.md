## Data Analytics in Everyday Life

| Concept                                  | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Data Analytics**                       | - Science of Data<br>- **Think:** *"turning data into insights"*<br>                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Data**                                 | - Collection of facts <br>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Data Process**                         | - Ask<br>- Prepare<br>- Process<br>- Analyze<br>- Share<br>- Act<br>- *You may not run through all of these stages linearly!* You may have to go back through, but don't skip steps.<br>- Review your work through each stage of the process for quality results                                                                                                                                                                                                                                                                      |

## How Data Informs Better Decisions
| Concept                         | Notes                                                                                                                                                                                                             |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Data-Driven Decision-Making** | - Using facts to guide business strategy<br> &emsp;• The first step is figuring out the business need                                                                                                             |
| **Subject-Matter Experts**      | - Have the ability to look at the results of data analysis and identify inconsistencies, make sense of gray areas, and validate the changes being made.                                                           |
| **Gut Instinct**                | - It can be helpful, but *don't make decisions based on it without any data to back it up!*<br>- Balancing data and gut instinct is crucial. <br> &emsp;• The right mix depends on resources and time constraints |
| **Solving Mysteries**           | - The more you understand the data related to a project, the easier it will be to figure out what is required.<br>                                                                                                |
| **Questions to Ask Yourself**   | - What kind of results are needed?<br>- Who will be informed?<br>- Am I answering the question being asked?<br>- How quickly does a decision need to be made?                                                     |

## Summary

Data analysis involves collecting, transforming, and organizing data. Data is a collection of facts. A goal of data analysis is to draw conclusions. When you think "Data Analytics", think "turning data into insights". Data is a collection of facts about something. There are several data analytics processes that are used across the profession. The main similarities include asking questions about the data, analyzing and visualizing the data, and presenting the data.

A data ecosystem encompasses the various elements that interact with one another in order to produce, manage, store, organize, analyze, and share data. When building data into business strategy, it's important to include insights from subject-matter experts (SMEs) because they are familiar with the business problem, they can review analysis results and help identify any inconsistencies, and their experience and human intuition are valuable to data-driven decision-making.
