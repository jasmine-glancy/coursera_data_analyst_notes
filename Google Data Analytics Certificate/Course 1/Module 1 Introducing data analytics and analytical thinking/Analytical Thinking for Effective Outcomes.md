| Concept                       | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Analytical Thinking**       | - Involves identifying and defining a problem and then solving it by using data in an organized, step-by-step way<br>- Five key aspects:<br>1. Visualization<br>2. ## Summary

To execute a plan using detail-oriented thinking, a data analyst must consider the specifics. Analytical thinking involves identifying and defining a problem, then solving it by using data in an organized, step-by-step manner. An analyst might create a graph, map, or chart in order to communicate data insights to others. Gap analysis is a method for examining and evaluating how a process works currently in order to get an improved future state.
