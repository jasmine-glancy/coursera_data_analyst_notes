## Cues

- What SQL statement filters the data based on certain conditions?
- Which part of the following query requests that all columns from the table be selected?
- Which part of the following query indicates the table from which to retrieve data?
- Give an example of a scenario where a line chart would be the most appropriate visualization.

---

## Summary

A data analyst uses SQL query to retrieve information from a database. They add a WHERE statement to filter the data based on certain conditions. The Asterisk (`*`) of a query requests all columns from the table be selected. The `FROM` part of the query indicates the table from which to retrieve data.
