# Module 3: Set Up Your Data Analytics Toolbox

## Master Spreadsheet Basics

| Concept         | Notes                                                                                                                                                                                                |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Attribute**   | - A characteristic or quality of data used to label a column in a table <br> &emsp;• More commonly referred to as column names, column labels, headers, or the header row.                           |
| **Observation** | - All of the attributes for something contained in a row of data                                                                                                                                     |
| **Formula**     | - A set of instructions that performs a set of instructions that performs a specific action using the data in a spreadsheet <br> &emsp;• The formula uses cell references for values its calculating |

## Summary

In a table, an attribute is a characteristic or quality of data used to label a column. Text wrap is used to change the height of a cell to allow the text inside to fit. Overflow allows the text to continue into the next cell if it is empty. Wrap forces the text to wrap the next line within the same cell. 

A set of instructions that performs a set of instructions that performs a specific action using the data in a spreadsheet. The equal sign (=) is used to start a formula in a spreadsheet.
