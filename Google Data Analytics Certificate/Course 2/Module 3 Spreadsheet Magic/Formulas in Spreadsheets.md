## Formulas in Spreadsheets

| Concept                      | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Formula**                  | - A set of instructions that perform a specific calculation<br>&emsp;• They can do math for you<br>&emsp;• Start with an equal sign `=`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Operator**                 | - A symbol that names the type of operation or calculation to be performed <br>&emsp;• Subtraction: minus sign (`-`)<br>&emsp;• Addition: plus sign (`+`)<br>&emsp;• Division: forward-slash (`/`)<br>&emsp;• Multiplication: asterisk (`*`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Cell Reference**           | - A cell or range of cells in a worksheet that can be used in a formula                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Range**                    | - A collection of two or more cells                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Auto-Filling**             | - The lower-right corner of each cell has a fill handle<br>&emsp;• It is a small _green square_ in Microsoft Excel<br>&emsp;• Small _blue circle_ in Google Sheets. <br><br>- Click the fill handle square or circle for a cell and drag it down a column<br>&emsp;• *Auto-fills other cells in the column* with the same value or formula in that cell<br>    <br>- Click the fill handle square or circle for a cell and drag it across a row<br>&emsp;• *Auto-fills other cells in the row* with the same value or formula in that cell <br>    <br>- **If you want to create a numbered sequence in a column or row, do the following:**<br>&emsp;1) Fill in the first two numbers of the sequence in two adjacent cells<br>&emsp;2) Select to highlight the cells<br>&emsp;3) Drag the fill handle square or circle to the last cell to complete the sequence of numbers |
| **Absolute Referencing**     | - Marked by a dollar sign (`$`) <br>&emsp;• For example, `=$A$10` has absolute referencing for both the column and the row value<br>&emsp;• Absolute references will <u>not</u> change when you copy and paste the formula in a different cell. *The cell being referenced is always the same.*<br><br>- To easily switch between absolute and relative referencing in the formula bar, highlight the reference you want to change and press the **F4** key; for example, if you want to change the absolute reference, `$A$10`, in your formula to a relative reference, `A10`, highlight `$A$10` in the formula bar and then press the **F4** key to make the change.                                                                                                                                                                                                       |
| **Relative References**      | - i.e. `=A10` <br>- Will change anytime the formula is copied and pasted<br>- They are in relation to where the referenced cell is located<br>&emsp;• if you copied `=A10` to the cell to the right it would become `=B10`<br>&emsp;• With absolute referencing, `=$A$10` copied to the cell to the right would remain `=$A$10`<br>&emsp;&emsp;• But if you copied `$A10` to the cell below, it would change to `$A11` because the row value isn't an absolute reference.                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Data Range**               | - When you click into your formula, the colored ranges let you see which cells are being used in your spreadsheet<br>- There are different colors for each unique range in your formula                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Combining with Functions** | - `COUNTIF()` is a formula and a function. This means the function runs based on criteria set by the formula<br>&emsp;• In this case, `COUNT` is the formula; it will be executed IF the conditions you create are true<br>&emsp;• For example, you could use `=COUNTIF(A1:A16, “7”)` to count only the cells that contained the number 7<br><br>- Combining formulas and functions allows you to do more work with a single command                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `#DIV/0!`                    | - A formula is trying to divide a value in a cell by 0 or by an empty cell  <br>&emsp;• To avoid this problem, use an IFERROR function                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `#ERROR!`                    | - Google Sheets only  <br>- A formula can’t be interpreted as input  <br>- Also known as a parsing error  <br>- Can happen with formula errors                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `#N/A`                       | - Data in a formula can’t be found by the spreadsheet  <br>- Can mean the data doesn’t exist  <br>- Most often occurs when using functions such as VLOOKUP                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **VLOOKUP**                  | - Searches for a certain value in a column to return a corresponding piece of information                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `#NAME?`                     | - A formula or function name isn’t understood  <br>- For example, a typo in the formula                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `#NUM!`                      | - A formula or function can’t be performed as specified  <br>&emsp;• To fix, double-check the formula/function                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **DATEDIF**                  | - Spreadsheet formula to calculate the number of months between start and end dates  <br>- Requires the start date to be the first cell referenced and the end date to be the second cell referenced                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `#VALUE!`                    | - A general error that could indicate a problem with a formula or referenced cells  <br>&emsp;• To fix, work through the cells and ensure the values used in the formula match the data types expected                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `#REF!`                      | - A formula is referencing a cell that is no longer valid or has been deleted  <br>&emsp;• To fix, ensure the reference range is updated                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## Summary

Spreadsheets are a valuable tool for data analysis. If you understand formulas, functions, and common errors, you can expedite your quality control process. Using the [[Spreadsheet Errors and Fixes]] sheet, you can quickly identify and debug various errors across both Google Sheets and Microsoft Excel.

In spreadsheets, the symbols used in a formula to perform a specific calculation are called operators. A forward slash (`/`) is the operator for a formula that uses division. A cell reference is composed of the letter of the cell’s column and the number of its row. The error message `ERROR` (also called a parsing error) will appear when a formula cannot be interpreted as it is written. To resolve a `NAME` error, ensure the formula name is correct.
