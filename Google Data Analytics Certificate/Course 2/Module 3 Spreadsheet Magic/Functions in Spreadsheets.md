## Functions in Spreadsheets

| Concept                               | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Function**                          | - A present command that automatically performs a specific process or task using the data  <br>- Have names that tell you what they do  <br>- They don’t always need operators  <br>- Start with an equals sign (`=`)  <br>- After you enter the equal sign, most spreadsheet applications will display an autocomplete menu that lists valid functions, names, and text strings  <br>&emsp;• Helps you avoid syntax errors  <br>- Try typing an equal sign and a single letter of the alphabet to learn new functions!  <br>- Popular shortcuts: [Chromebook](https://support.google.com/chromebook/answer/183101?hl=en), [PC](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec), and [Mac](https://support.apple.com/en-us/HT201236)                                                                           |
| **Colon (`:`)**                       | Tells the function you’re using a range of cells\|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Fill Handle**                       | - It's a little box that appears in ​the lower right-hand corner when you click on a cell  <br>- If you rest your cursor on the box, ​you can then drag the fill handle to ​the other boxes in the same row or column  <br>- Any formula or function in that cell will ​automatically be added to the cells you fill plus, ​the fill handle will update the formula so ​the cell references match ​the row of the columns of the cells you fill.  <br>- Filling won’t work for every situation, but it’s useful in a lot of situations                                                                                                                                                                                                                                                                                                                                         |
| **MIN**                               | - Short for minimum  <br>- Shows the lowest value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **MAX**                               | - Short for maximum  <br>- Shows the highest value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Relative References**               | - Cells referenced without a dollar sign, like `A2`  <br>- Change when you copy and paste the function into a different cell  <br>- The location of the cell that contains the function determines the cells used by the function                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Absolute References**               | - Cells fully referenced with a dollar sign, like `A2`  <br>- Will not change when you copy and paste the function into a different cell  <br>- The cells referenced always remain the same                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Mixed References**                  | - Cells partially referenced with a dollar sign, like `$A2` or `A$2`  <br>- Will change when you copy and paste the function into a different cell  <br>- The location of the cell that contains the function determines the cells used by the function, but only the row or column is relative (not both)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Toggling References**               | - In spreadsheets, you can press the `F4` key to toggle between relative, absolute, and mixed references in a function  <br>- Click the cell containing the function, highlight the referenced cells in the formula bar, and then press `F4` to toggle between and select relative, absolute, or mixed referencing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Data Ranges**                       | - When you click a cell that contains a function, **colored data ranges in the formula bar** indicate which cells are being used in the spreadsheet  <br>- There are different colors for each unique range in a function  <br>- Colored data ranges help prevent you from getting lost in complex functions.<br>- In spreadsheets, you can press the F2 key to highlight the range of data used by a function  <br>- Click the cell containing the function, highlight the range of data used by the function in the formula bar, and then press F2. The spreadsheet will go to and highlight the cells specified by the range.                                                                                                                                                                                                                                               |
| Data ranges evaluated for a condition | - `COUNTIF` is an example of a function that returns a value based on a condition that the data range is evaluated for  <br>- The function counts the number of cells that meet the criteria <br>- For example, in an expense spreadsheet, use `COUNTIF` to count the number of cells that contain a reimbursement for "airfare."<br>For more information, refer to:<br>&emsp;• [Microsoft Support's page for COUNTIF](https://support.microsoft.com/en-us/office/countif-function-e0de10c6-f885-4e71-abb4-1f464816df34)<br>&emsp;• [Google Help Center's documentation for COUNTIF](https://support.google.com/docs/answer/3093480?hl=en) where you can copy a sheet with [COUNTIF examples](https://docs.google.com/spreadsheets/d/1PYoKCYZAkWSaMBsiTyvxZzCCt2WQ-QKOC763RWHMB7c/template/preview) (click "Use Template" if you click the COUNTIF link provided on this page) |

## Cues 

- Which of the following functions counts how many items in a range of cells meet a given criterion?
- How does using functions help you quickly gain insights into large amounts of data?
- How does creating a data table help you organize and communicate important aspects of your data?
- What is the correct way to write a function that will find the average of all values in the range of cells from F1 to F10 in a spreadsheet?

---

## Summary

Using keyboard shortcuts make working in Excel or Google Sheets faster. Using `COUNTIF` counts how many items in a range of cells meet a given criterion. While you could use a formula like `=A1+A2+A3`, it's time inefficient and prone to errors the more cells you're referencing. However, using functions like SUM instead can ensure you get the entire range of cells within a column, reducing the chance of human error. 

Creating a data table helps you organize and communicate important aspects of your data by showing totals, minimums, maximums, and averages. `AVERAGE` is a spreadsheet function that returns an average of the values from a selected range. To find the average of all values between cells F1 and F10, the function is `=AVERAGE(F1:F10)`. `SUM` is a spreadsheet function that adds the values of a selected range of cells. `MIN` is a spreadsheet function that returns the smallest numeric value from a range of cells. `MAX` is a spreadsheet function that returns the largest numeric value from a range of cells.
