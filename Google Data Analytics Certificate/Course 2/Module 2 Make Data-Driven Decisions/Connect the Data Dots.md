## Summary

Small data tends to focus on specific metrics, is organized and analyzed using spreadsheets, and can be useful when making day-to-day decisions. Big data typically involves large datasets containing data from long time periods, which has to be organized before analysis. Big data is typically stored in a database and requires SQL for sorting and analysis. Spreadsheets are more effective when using small data.

The four V words describe the the benefits and challenges of big data: volume,  variety, velocity, and veracity. Volume which describes the amount of data being analyzed. Variety describes different kinds of data. Velocity describes how fast the data can be processed. Veracity is the quality and reliability of the data.
