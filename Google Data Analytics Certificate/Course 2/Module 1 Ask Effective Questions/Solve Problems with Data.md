# Course 2: Ask Questions to Make Data-Driven Decisions

## Solve Problems with Data

| Concept                        | Notes                                                                                                                                                                                                                               |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Problems**                   | - Think of problems as opportunities to put your skills to work and find creative and insightful solutions<br>- Small or large, simple or complex, you first have to *understand the problems you are trying to solve*              |
| **Problem Types**              | 1. Making Predictions<br>2. Categorizing things<br>3. Spotting something unusual<br>4. Identifying themes<br>5. Discovering connections<br>6. Finding patterns                                                                      |
| **Making Predictions**         | - Involves using data to make an informed decision about how things may be seen in the future <br>- **Example:** a hospital uses remote patient monitoring to predict health events for chronically ill patients                    |
| **Categorizing Things**        | - Assign information to different groups or clusters based on common features <br>- **Example:** Top/bottom in categories                                                                                                           |
| **Spotting Something Unusual** | - Identify data that is different from the norm<br>- **Example:** A sudden increase in the number of students registered                                                                                                            |
| **Identifying Themes**         | - Group categorized information into broader concepts<br>- Helpful to sub-categorize after you've already *Categorized Things*                                                                                                      |
| **Discovering Connections**    | - Enables data analysts to find similar challenges faced by different entities, and then combine data and insights to address them<br>- Discussing problems and sharing data openly can enable us to collaborate to find a solution |
| **Finding Patterns**           | - Using historical data to understand what happened in the past and is therefore likely to happen again                                                                                                                             |
| **User Experience Designers**  | - Study and work to improve the interactions people have with the products they use every day                                                                                                                                       |

## Summary

There are six main problem types you will see as a data analyst. Making predictions involves using data to make informed decisions about how things may be in the future. Categorizing things involves grouping data based on common features. Spotting something unusual involves identifying data that is different from the norm. Identifying themes involves recognizing broader concepts and trends from categorized data

Discovering connections involves identifying similar challenges across different entities—and using data and insights to find common solutions. Finding patterns involves using historical data about what happened in the past to understand how likely it is to happen again
