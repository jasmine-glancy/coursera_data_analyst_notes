## Tableau Dashboards

| Concept              | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Dashboard Design** | - Start with the most important data points<br>- You can always add more later<br>- Placement of charts, graph, and other visuals is important!<br>- ​**Tiled items** are part of a single-layer grid that ​automatically resizes based on ​the overall dashboard size<br>- **​Floating items** can be layered over other objects. ​                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Static Data**      | - Involves providing screenshots or snapshots in presentations or building dashboards using snapshots of data. There are pros and cons to static data.<br>- **PROS:**<br>&emsp;• Can tightly control a point-in-time narrative of the data and insight<br>&emsp;• Allows for complex analysis to be explained in-depth to a larger audience<br>    <br>- **CONS**<br>&emsp;• Insight immediately begins to lose value and continues to do so the longer the data remains in a static state<br>&emsp;• Snapshots can't keep up with the pace of data change                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Live Data**        | - You can build dashboards, reports, and views connected to automatically updated data. <br>    <br>- **PROS:**<br>&emsp;• Dashboards can be built to be more dynamic and scalable<br>&emsp;• Gives the most up-to-date data to the people who need it at the time when they need it<br>&emsp;• Allows for up-to-date curated views into data with the ability to build a scalable “single source of truth” for various use cases<br>&emsp;• Allows for immediate action to be taken on data that changes frequently<br>&emsp;• Alleviates time/resources spent on processes for every analysis<br>    <br>- **CONS:**<br>&emsp;• Can take engineering resources to keep pipelines live and scalable, which may be outside the scope of some companies' data resource allocation<br>&emsp;• Without the ability to interpret data, you can lose control of the narrative, which can cause data chaos (i.e. teams coming to conflicting conclusions based on the same data)<br>&emsp;• Can potentially cause a lack of trust if the data isn’t handled properly |

## Summary

Filters in Tableau can be used to limit information, customize information, or highlight a data point. The key objectives of using a dashboard to organize information from multiple datasets into one central location include tracking, analyzing, and visualizing data. Dashboard visuals must be cohesive, which means that they are balanced and make good use of space. If you want your Tableau dashboard to automatically resize itself based on the overall dashboard size, choose a tiled layout. A data analyst might use filters to highlight individual data points or zero in on what is important to stakeholders.
