# Module 1: Organize Data for More Effective Analysis

## Sort Data in Spreadsheets

| Concept                   | Notes                                                                                                                                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Sort Sheet**            | - All of the data in a spreadsheet is sorted by the ranking of a specific sorted column - data across rows is kept together                                                                                                                             |
| **Sort Range**            | - Nothing else on the spreadsheet gets ​rearranged but the specified cells                                                                                                                                                                              |
| **`SORT` Function**       | - Sorts your data in spreadsheets <br>- `=SORT(start:end of reference data, start:end of sorting data without column letters, ascending or descending order)`<br>&emsp;• Write `TRUE` for ascending order<br>&emsp;• Write `FALSE` for descending order |
| **Customized Sort Order** | - When you sort data in a spreadsheet using multiple conditions<br>&emsp;• Sorting is based on the order of the conditions you select                                                                                                                   |
| **Descending**            | - Z to A order<br>- Last to first<br>- Excel offers largest to smallest<br>- Most recent to least recent                                                                                                                                                |
| **Ascending**             | - A to Z order <br>- First to last<br>- Excel offers smallest to largest<br>- Least recent to most recent                                                                                                                                               |

## Summary

The sort from a spreadsheet's Data tab overwrites the cells containing the unsorted data with the sorted data, while a written `SORT` function inserts the sorted data in a different cell range. The sort from a spreadsheet's Data tab can exclude a header row in the data range from being sorted, while the data range for a written `SORT` function should never contain a header row. Sort sheet sorts all spreadsheet data by the ranking of a specific sorted column. When using the `SORT` function in spreadsheets, a `FALSE` statement will return the data in ascending order. A customized sort order involves sorting data in a spreadsheet using multiple conditions. This means that the sorting will be based on the order of the conditions selected. A data professional selects “Data has a header row” when sorting data in a spreadsheet to ensure the first row of data is treated as header labels instead of data points.
