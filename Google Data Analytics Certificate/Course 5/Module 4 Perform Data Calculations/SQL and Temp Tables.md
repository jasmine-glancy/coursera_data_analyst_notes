## SQL and Temp Tables

| Concept                                 | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Temporary Tables**                    | - A database table that is created and exists temporarily on a database server<br>- Store subsets of data from standard data tables for a certain period of time<br>- Automatically deleted when you end your SQL database session                                                                                                                                                                                                                                                                        |
| **Uses for Temporary Tables**           | - When you only need a table for a short time to complete analysis tasks like calculations                                                                                                                                                                                                                                                                                                                                                                                                                |
| **`WITH`**                              | - A type of temporary table you can query from multiple times<br>- Approximates a temporary table<br>&emsp;• Creates something that does the same thing as a temporary table                                                                                                                                                                                                                                                                                                                              |
| **`SELECT INTO`**                       | - Copies data from one table into a new table, but doesn’t add the new table to the database <br>- Useful if you want to make a copy of a table with a specific condition<br>- Good practice when you want to keep the database uncluttered and you don’t need other people using the table<br>- Not supported by BigQuery                                                                                                                                                                                |
| **`CREATE TABLE`**                      | - A good option when several people need to access the same temp table <br>- Adds the table into the database<br>- Useful if the code is difficult to replicate                                                                                                                                                                                                                                                                                                                                           |
| **Global vs. local temporary tables**   | - Global temporary tables are made available to all database users and are deleted when all connections that use them have closed<br>- Local temporary tables are made available only to the user whose query or connection established the temporary table<br>- If you have created a local temporary table and are the only person using it, you can drop the temporary table after you are done using it                                                                                               |
| **Dropping temporary tables after use** | - Dropping a temporary table is a little different from deleting a temporary table <br>- Dropping a temporary table not only removes the information contained in the rows of the table, but removes the table variable definitions (columns) themselves<br>- Deleting a temporary table removes the rows of the table but leaves the table definition and columns ready to be used again<br>- Although local temporary tables are dropped after you end your SQL session, it may not happen immediately. |

## Summary

A temporary table is created and exists for a short time on a database server. Rather than filter data over and over, you can create a temporary table. `WITH` clauses, `CREATE TABLE` statements, and `CREATE TEMP TABLE` statements all create temporary tables in queries. The temporary table will be automatically deleted after ending the session in the SQL database. A data analyst uses `SELECT INTO` to copy data from one table into a temporary table without adding the new table to the database. This is useful for making a copy of a table with a specific condition. A data professional might add a `CREATE TABLE` statement to a temporary table to give multiple people access.
