## Summary

There are six main types of data validation: Data type, data range, data constraints, data consistency, data structure, and code review.  Data type validation checks that data matches the data type defined for a field. Data range validation checks the data falls within an acceptable range of values defined for the field. Data Constraint validation checks the data meets certain conditions or criteria for a field, including the type of data entered as well as other attributes of the field like number or characters.

Data may be consistent, but it can still be incorrect or inaccurate. For example, a shipping date that’s later than production date, but it’s wrong. Data structure checks the data follows or conforms to a set structure. Code validation checks that an application’s code systemically performs any of the previously mentioned validations during the user data input.
