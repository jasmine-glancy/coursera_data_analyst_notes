# Module 4: Perform Data Calculations 

## Get Started with Data Calculations

| Concept                    | Notes                                                                                                                                                                  |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`SUMPRODUCT`**           | - Adds and multiplies all in one step                                                                                                                                  |
| **Conditional Formatting** | - A spreadsheet tool that changes how cells appear when values meet specific conditions                                                                                |
| **`COUNTIF` Function**     | - Returns the number of cells that match a specified value <br>- `=COUNTIF(range, “value”)`                                                                            |
| **`SUMIF` Function**       | - A function that adds numeric data based on one condition <br>- `=SUMIF(range,criteria/condition,[sum_range])`<br>&emsp;• Adding a space after each comma is optional |
| **`SUMIFS` Function**      | - Similar to `SUMIF`, but can include multiple conditions.  <br>- `=SUMIFS(D2:D8, A2:A8, "ProductA", B2:B8, "East", C2:C8, "Q1")`                                      |
| **`COUNTIFS` Function**    | - Similar to `COUNTIF`, but can include multiple conditions<br>- `=COUNTIFS(A2:A8, "ProductA", B2:B8, "East", C2:C8, "Q2")`                                            |
| **`SUMPRODUCT`**           | - A function that multiplies arrays and returns the sum of those products <br>- `=SUMPRODUCT(array1, [array2]...)`                                                     |
| **Array**                  | - A collection of values in cells                                                                                                                                      |
| **Profit Margin**          | - A percentage that indicates how many cents of profit has been generated for each dollar of sale                                                                      |

## Summary

The spreadsheet function `COUNTIF` returns the number of cells within a range that match a specified value. The syntax is `=COUNTIF(range, criteria)`. An array is a collection of values in spreadsheet cells. The values in cells B2 through B31 is an example of an array.
