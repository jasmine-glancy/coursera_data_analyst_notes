## Summary

In Google Sheets, to convert the temperature in a cell from degrees Celsius to degrees Fahrenheit, the correct syntax for the CONVERT function is `=CONVERT(cellnumber, "C", "F")`. The “List of Items” option in the data validation menu will enable you to add a dropdown list with various options. A data professional uses paste values only in order to ensure spreadsheet values are static, rather than carrying over a preexisting formula or function.

Reject invalid inputs highlights data entry errors to ensure spreadsheet formulas continue to run correctly. Conditional formatting is a spreadsheet tool that changes how cells appear when values meet specific conditions.
