- What SQL clause can be added to this query to ensure only the first 50 results are returned?

## Summary

The function `CONCAT` combines groups of text strings from multiple cells in order to create a new string. The SQL clause `LIMIT 50` will ensure only the first 50 results are returned. The `ROUND` function will limit the records to two decimal places. `ROUND` returns a number rounded to a certain number of decimal places.
