## Summary

The `VALUE` function converts the text string to a numerical value. If you enter `FALSE` as the last input parameter in a `VLOOKUP` function,  `VLOOKUP` will search for an exact match. The purpose of data aggregation is to gather data from multiple sources in order to combine it into a single, summarized collection. The function `VALUE` can be used to change the text string in spreadsheet cells to a numerical value. Absolute references use `$` before each cell letter. The purpose of absolute references is to ensure the rows and columns will not change if the function is copied.
