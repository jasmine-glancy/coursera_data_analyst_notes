## Summary

Working with subqueries can reduce the number of single queries to the database, including making your queries more readable. Subqueries can add new columns to existing tables, filter results, and allow you to work with massive datasets to get answers to business problems. When working with subqueries, the innermost query will execute first. A data professional uses the SQL `CASE` statement to return records that meet conditions by including an if/then statement in a query.
