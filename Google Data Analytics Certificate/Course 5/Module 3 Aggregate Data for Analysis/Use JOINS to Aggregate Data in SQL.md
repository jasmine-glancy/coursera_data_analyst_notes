## Summary

A `JOIN` is the SQL version of a `VLOOKUP` in Excel. The `OUTER JOIN` clause enables an analyst to combine `RIGHT` and `LEFT JOIN` functionality to return matching records from either table. `JOIN` statements are important for working with relational databases because your data is spread out across various data tables. Depending on the information you need, you can filter in or out various data using `JOIN`s. If you choose the wrong kind of `JOIN`, you can inadvertently limit your information, hampering your analysis. Aliasing is most helpful for renaming columns, tables, and queries to clarify column headers.

To combine rows from two or more tables based on a related column, data professionals use the SQL JOIN clause. To retrieve only records from a database that have matching values in two different tables, the analyst should use `INNER JOIN`. `COUNT DISTINCT` will only count each value once, even if it appears multiple times. Aliasing involves temporarily naming a table or column to make a query easier to read and write.
