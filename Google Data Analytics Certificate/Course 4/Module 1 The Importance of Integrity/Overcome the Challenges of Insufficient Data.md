## Overcome the Challenges of Insufficient Data

| Concept                                                | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Business Objectives**                                | - Once you know your business objective, you'll be able to recognize whether you have enough data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Types of Insufficient Data**                         | - Using only one source<br>- Data that keeps updating<br>&emsp;• Or it may be too soon to see trends<br><br>- Outdated data<br>- Geographically-limited data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Ways to Address Insufficient Data**                  | - Identify trends with the available data<br>- Wait for more data if time allows<br>- Talk with stakeholders and adjust your objective                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Data Issue: No Data**                                | - Gather the data on a small scale to perform a preliminary analysis and then request additional time to complete the analysis after you have collected more data. <br>&emsp;• **Example**<br>&emsp; If you are surveying employees about what they think about a new performance and bonus plan, use a sample for a preliminary analysis<br>&emsp;&emsp; • Then, ask for another 3 weeks to collect the data from all employees.<br><br>- If there isn’t time to collect data, perform the analysis using proxy data from other datasets.<br>&emsp;• This is the most common workaround<br>&emsp;• **Example**<br>&emsp; IF you are analyzing peak travel times for commuters but don’t have the data for a particular city, use the data from another city with a similar size and demographic.                                                                                                                                                                                                                                                  |
| **Data Issue: Too Little Data**                        | - Do the analysis using proxy data along with actual data. <br>&emsp;• **Example**<br>&emsp;If you are analyzing trends for owners of golden retrievers, make your dataset larger by including the data from owners of labradors.<br><br>- Adjust your analysis to align with the data you already have.<br>&emsp;• **Example**<br>&emsp; If you are missing data for 18- to 24-year-olds, do the analysis but note the following limitation in your report: _this conclusion applies to adults 25 years and older_ _only_.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Data Issue: Wrong Data, Including Data with Errors** | - If you have the wrong data because requirements were misunderstood, communicate the requirements again<br>&emsp;• **Example**<br>&emsp; If you need the data for female voters and received the data for male voters, restate your needs<br><br>- Identify errors in the data and, if possible, correct them at the source by looking for a pattern in the errors.<br>&emsp;• **Example**<br>&emsp; If your data is in a spreadsheet and there is a conditional statement or boolean causing calculations to be wrong, change the conditional statement instead of just fixing the calculated values<br><br>- If you can’t correct data errors yourself, you can ignore the wrong data and go ahead with the analysis if your sample size is still large enough and ignoring the data won’t cause systematic bias<br>&emsp;• **Example**<br>&emsp; If your dataset was translated from a different language and some of the translations don’t make sense, ignore the data with bad translation and go ahead with the analysis of the other data |
| **Sample Size**                                        | - You use part of a population that's representative of the population as a whole <br>&emsp;• The ***goal is to get enough information from a small group within a population to make predictions***<br>&emsp;• The sample size helps ensure the degree to which you can be confident that your conclusions accurately represent the population <br><br>- Usually takes place before you get to the data<br><br>- Varies by business problem<br><br>- **Pros:**<br>&emsp;• More cost-effective and takes less time<br>&emsp;• If done thoughtfully and carefully, you can get the same results using a sample size instead of 100% of the sample<br><br>- **Cons:**<br>&emsp;• Can lead to uncertainty; you can't be 100% sure of their statistics<br>&emsp;• Can lead to sampling bias                                                                                                                                                                                                                                                            |
| **Sampling Bias**                                      | - When a sample isn't representative of the population as a whole <br>&emsp;• Some of the population is overrepresented or underrepresented<br>&emsp;• **Random sampling** can help with sampling bias                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Random Sampling**                                    | - A way of selecting a sample from a population so that every possible type of the sample has an equal chance of being chosen                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Population**                                         | - The entire group that you are interested in for your study <br>&emsp;• For example, if you are surveying people in your company, the population would be all the employees in your company                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Sample**                                             | - A subset of your population                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Margin of error**                                    | - Since a sample is used to represent a population, the sample’s results are expected to differ from what the result would have been if you had surveyed the entire population <br>- The smaller the margin of error, the closer the results of the sample are to what the result would have been if you had surveyed the entire population                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Confidence level**                                   | - How confident you are in the survey results <br>- Confidence level is targeted *before* you start your study because it will affect how big your margin of error is at the end of your study                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Confidence interval**                                | - The range of possible values that the population’s result <br>&emsp;• This range is the sample result +/- the margin of error                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Statistical significance**                           | - The determination of whether your result could be due to random chance or not <br>&emsp;• The greater the significance, the less due to chance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Things to Remember When Determining Sample Size**    | - Don’t use a sample size less than 30 <br>&emsp;• It has been statistically proven based on the ***Central Limit Theorem (CLT)*** that 30 is the smallest sample size where an average result of a sample starts to represent the average result of a population<br><br>- The confidence level most commonly used is 95%<br>&emsp;• 90% can work in some cases<br><br>- Increase the sample size to meet specific needs of your project:<br>&emsp;• For a **higher** confidence level, use a *larger* sample size<br>&emsp;• To **decrease** the margin of error, use a *larger* sample size    <br>&emsp;• For **greater** statistical significance, use a *larger* sample size<br><br>- Larger sample sizes have a higher cost                                                                                                                                                                                                                                                                                                                  |
| **Regression Analysis**                                | - Statistical methods to determine the relationships between controlled and dependent variables                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Insufficient Data**                                  | - One or more of the following problems:<br>&emsp;• Comes from only one source<br>&emsp;• Continuously updates and is incomplete<br>&emsp;• Is outdated<br>&emsp;• Is geographically limited<br><br>- To deal with insufficient data:<br>&emsp;• Identify trends within the available data<br>&emsp;• Wait for more data if you can<br>&emsp;• Discuss with stakeholders and adjust your objective<br>&emsp;• Search for a new dataset                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## Summary

If you have insufficient data, you can identify trends with the data that is available and qualify your findings accordingly. You can choose to use smaller-scale data until you can find more complete data or locate another relevant dataset to work with. You could also consider whether it is possible to adjust the objective if your stakeholders consent.

Limitations that might lead to insufficient data include data that updates continually, outdated data, and data from a single source. Sampling bias occurs when some members of a population are overrepresented or underrepresented in the data.
