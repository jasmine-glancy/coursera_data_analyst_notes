## Summary

`CAST()` is a SQL function used to convert data types from one type to another. `INSERT INTO` is a SQL command a data analyst can use to add information to a database. The SQL command `DROP TABLE IF EXISTS` is irreversible, so data analysts should consider whether data should be backed up before using it. You can use `COALESCE()` to replace null values with a value in a different column.
