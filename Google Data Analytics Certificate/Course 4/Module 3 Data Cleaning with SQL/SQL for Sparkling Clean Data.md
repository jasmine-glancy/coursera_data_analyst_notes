## Cues

- A team of analysts is working on a data analytics project. How could data in a SQL database be more useful to the team than data in spreadsheets?
- What should you use if you have a smaller dataset?

---

## Summary

Data stored in a SQL database is useful to a project with multiple team members because they can access the data at the same time, use SQL to interact with the database program, and track changes to SQL queries across the team. If you have a smaller dataset or if the dataset lives in a spreadsheet, your analysis should be completed within the spreadsheet.
