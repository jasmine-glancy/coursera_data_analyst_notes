# Course 4: Process Data from Dirty to Clean

## Module Table of Contents
### Module 1: The Importance of Integrity
Data integrity is critical to successful analysis. In this part of the course, you’ll explore methods and steps that analysts take to check their data for integrity. This includes knowing what to do when you don’t have enough data. You’ll also learn about random samples and understand how to avoid sampling bias. All of these methods will also help you ensure your analysis is successful.

### Module 2: Clean Data for More Accurate Insights
Every data analyst wants to analyze clean data. In this part of the course, you’ll learn the difference between clean and dirty data. Then, you’ll practice cleaning data in spreadsheets and other tools.

### Module 3: Data Cleaning with SQL
Knowing a variety of ways to clean data can make a data analyst’s job much easier. In this part of the course, you’ll use SQL to clean data from databases. In particular, you’ll explore how SQL queries and functions can be used to clean and transform your data before an analysis.

### Module 4: Verify and Report on Cleaning Results
When you clean data, you make changes to the original dataset. It’s important to verify the changes you make are accurate and to let your teammates know about the changes. In this part of the course, you’ll learn to verify that data is clean and report your data cleaning results. With verified clean data, you’re ready to begin analyzing!

### Module 5: Add Data to Your Resume
Creating an effective resume will help you in your data analytics career. In this part of the course, you’ll learn all about the job application process. Your focus will be on building a resume that highlights your strengths and relevant experience.

## Terms

| Term                                    | Notes                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Accuracy**                            | - The degree to which the data conforms to the actual entity being measured or described <br>&emsp;• If values for zip codes are validated by street location, the accuracy of the data goes up.                                                                                                                                                                                                      |
| **Cleaning**                            | - Document your cleaning process                                                                                                                                                                                                                                                                                                                                                                      |
| **Completeness**                        | - The degree to which the data contains all desired components or measures <br>&emsp;• If data for personal profiles required hair and eye color, and both are collected, the data is complete.                                                                                                                                                                                                       |
| **Confidence level**                    | - How confident you are in the survey results <br>- Confidence level is targeted *before* you start your study because it will affect how big your margin of error is at the end of your study<br>&emsp;• Most industries prefer 90-95% confidence level                                                                                                                                              |
| **Confidence interval**                 | - The range of possible values that the population’s result <br>&emsp;• This range is the sample result +/- the margin of error                                                                                                                                                                                                                                                                       |
| **Contraindication**                    | - A condition that may cause a patient not to take a vaccine or a medication due to the harm it may cause if taken                                                                                                                                                                                                                                                                                    |
| **Consistency**                         | - The degree to which the data is repeatable from different points of entry or collection <br>&emsp;• If a customer has the same address in the sales and repair databases, the data is consistent.                                                                                                                                                                                                   |
| **Cross-field validation**              | - Certain conditions for multiple fields must be satisfied <br>&emsp;• Values are percentages and values from multiple fields must add up to 100%                                                                                                                                                                                                                                                     |
| **Data Alignment**                      | - You can gain powerful insights and make accurate conclusions when the data is well-aligned to the business objectives <br>&emsp;• Good alignment means the data is relevant, can help you solve a business problem, or determine a course of action to achieve a given business objective                                                                                                           |
| **Data Integrity**                      | - The accuracy, completeness, ​consistency, and trustworthiness of ​data throughout its lifecycle<br>- Can be compromised every time it’s replicated, transferred, or manipulated in any way<br>&emsp;• **Other threats to data integrity** include human error, viruses, malware, hacking, and system failures<br><br>- The data warehouse and data engineering teams can help ensure data integrity |
| **Data Integrity Checklist**            | 1. Clean your data<br>2. Check for data integrity<br>3. Check the data you use aligns with the business objective!                                                                                                                                                                                                                                                                                    |
| **Data Replication**                    | - The process of storing data in multiple locations <br>- This can cause inconsistencies                                                                                                                                                                                                                                                                                                              |
| **Data Range**                          | - Values must fall between predefined maximum and minimum values <br>&emsp;• Ex: If the data range is 10-20, a value of 30 would fail the constraint and be invalid                                                                                                                                                                                                                                   |
| **Data Transfer**                       | - The process of copying data from a storage device to memory, or from one computer to another <br>- Interrupting this can cause incomplete datasets                                                                                                                                                                                                                                                  |
| **Data Type**                           | - Values must be of a certain type, such as date, number, percentage, Boolean, etc <br>&emsp;• Ex: If the data type is a date, a single number like 30 would fail the constraint and be invalid                                                                                                                                                                                                       |
| **Data Manipulation**                   | - The process of changing data to make it more organized and easier to read<br>- Meant to make data analysis more efficient, but an error during the process can compromise it                                                                                                                                                                                                                        |
| **Estimated response rate**             | - If you are running a survey of individuals, this is the percentage of people you expect will complete your survey out of those who received the survey                                                                                                                                                                                                                                              |
| **Foreign-key**                         | - (Databases only) values for a column must be unique values coming from a column in another table <br>&emsp;• In a U.S. taxpayer database, the State column must be a valid state or territory with the set of acceptable values defined in a separate States table                                                                                                                                  |
| **Hypothesis Testing**                  | - A way to see if a survey or experiment has meaningful results                                                                                                                                                                                                                                                                                                                                       |
| **Margin of error**                     | - Since a sample is used to represent a population, the sample’s results are expected to differ from what the result would have been if you had surveyed the entire population <br>- The smaller the margin of error, the closer the results of the sample are to what the result would have been if you had surveyed the entire population                                                           |
| **Mandatory**                           | - Values can’t be left blank or empty <br>&emsp;• If age is mandatory, that value must be filled in                                                                                                                                                                                                                                                                                                   |
| **Primary-key**                         | - (Databases only) value must be unique per column <br>&emsp;• A database table can’t have two rows with the same primary key value. A primary key is an identifier in a database that references a column in which each value is unique. More information about primary and foreign keys is provided later in the program.                                                                           |
| **Population**                          | - The entire group that you are interested in for your study <br>&emsp;• For example, if you are surveying people in your company, the population would be all the employees in your company                                                                                                                                                                                                          |
| **Random Sampling**                     | - A way of selecting a sample from a population so that every possible type of the sample has an equal chance of being chosen                                                                                                                                                                                                                                                                         |
| **Regression Analysis**                 | - Statistical methods to determine the relationships between controlled and dependent variables                                                                                                                                                                                                                                                                                                       |
| **Regular expression (regex) patterns** | - Values must match a prescribed pattern <br>&emsp;• A phone number must match ###-###-#### (no other characters allowed)                                                                                                                                                                                                                                                                             |
| **Sampling Bias**                       | - When a sample isn't representative of the population as a whole <br>&emsp;• Some of the population is overrepresented or underrepresented<br>&emsp;• **Random sampling** can help with sampling bias                                                                                                                                                                                                |
| **Sample**                              | - A subset of your population                                                                                                                                                                                                                                                                                                                                                                         |
| **Sample Size**                         | - Part of a population that's representative of the population as a whole <br>&emsp;• The ***goal is to get enough information from a small group within a population to make predictions***<br>&emsp;• The sample size helps ensure the degree to which you can be confident that your conclusions accurately represent the population                                                               |
| **Statistical Power**                   | - The probability of getting meaningful results from a test                                                                                                                                                                                                                                                                                                                                           |
| **Statistical significance**            | - The determination of whether your result could be due to random chance or not <br>&emsp;• The greater the significance, the less due to chance                                                                                                                                                                                                                                                      |
| **Set-membership**                      | - (Databases only) values for a column must come from a set of discrete values <br>&emsp;• Value for a column must be set to Yes, No, or Not Applicable                                                                                                                                                                                                                                               |
| **Unique**                              | - Values can’t have a duplicate <br>&emsp;• Two people can’t have the same mobile phone number within the same service area                                                                                                                                                                                                                                                                           |
