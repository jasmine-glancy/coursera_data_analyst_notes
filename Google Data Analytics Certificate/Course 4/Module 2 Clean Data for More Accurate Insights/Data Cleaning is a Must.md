## Data Cleaning is a Must!

| Concept                                       | Notes                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **#1 Most Common Cause of Poor Quality Data** | - Human error!                                                                                                                                                                                                                                                                                                                                         |
| **Dirty Data**                                | - Data that is incomplete, incorrect, or irrelevant to the problem you're trying to solve <br><br>- ***Can be the result of...***<br>&emsp;• Incorrect data entry<br>&emsp;• Inconsistent formatting<br>&emsp;• Blank fields<br>&emsp;• The same piece of data being entered more than once (duplicates)                                               |
| **Clean Data**                                | - Data that is complete, correct, and relevant to the problem you are trying to solve                                                                                                                                                                                                                                                                  |
| **Data Engineers**                            | - Transform data into ​a useful format for ​analysis and give it a reliable infrastructure <br>&emsp;• Develop, maintain, ​and test databases, data processors and related systems                                                                                                                                                                     |
| **Data Warehousing Specialists**              | - Develop processes ​and procedures to effectively store and organize data <br>&emsp;• They make sure that data is available, ​secure, and backed up to prevent loss                                                                                                                                                                                   |
| **NULL**                                      | - The value does not exist in a dataset<br><br>- **Handling `NULL` in your Dataset**<br>&emsp;• Remove them from the samples and explain that the results do not include them<br>&emsp;• Keep them in and learn from why                                                                                                                               |
| **Duplicate Data**                            | - Any data record that shows up more than once <br><br>- **Possible Causes:**<br>&emsp;• Manual data entry<br>&emsp;• Batch data imports<br>&emsp;• Data migration<br><br>- **Potential harm to businesses:**<br>&emsp;• Skewed metrics or analyses<br>&emsp;• Inflated or inaccurate counts or predictions<br>&emsp;• Confusion during data retrieval |
| **Outdated Data**                             | - Any data that is old which should be replaced with newer and more accurate information<br><br>- **Possible Causes:**<br>&emsp;• People changing roles or companies<br>&emsp;• Software and systems becoming obsolete<br><br>- **Potential harm to businesses:**<br>&emsp;• Inaccurate insights, decision-making, and analytics                       |
| **Incomplete Data**                           | - Any data that is missing important fields <br><br>- **Possible Causes:**<br>&emsp;• Improper data collection<br>&emsp;• Incorrect data entry<br><br>- **Potential harm to businesses:**<br>&emsp;• Decreased productivity<br>&emsp;• Inaccurate insights<br>&emsp;• Inability to complete essential services                                         |
| **Incorrect/inaccurate data**                 | - Any data that is complete but inaccurate<br><br>- **Possible Causes:**<br>&emsp;• Human error inserted during data input<br>&emsp;• Fake information<br>&emsp;• Mock data<br><br>- **Potential harm to businesses:**<br>&emsp;• Inaccurate insights<br>&emsp;• Decision-making based on bad information resulting in revenue loss                    |
| **Inconsistent data**                         | - Any data that uses different formats to represent the same thing<br><br>- **Possible Causes:**<br>&emsp;• Data stored incorrectly<br>&emsp;• Errors inserted during data transfer<br><br>- **Potential harm to businesses:**<br>&emsp;• Contradictory data points leading to confusion<br>&emsp;• Inability to classify or segment customers<br>     |
| **Field Length**                              | - A tool for determining ​how many characters can be keyed into a field                                                                                                                                                                                                                                                                                |
| **Data Validation**                           | - A tool for checking the accuracy and quality of data before adding or importing it<br>&emsp;• A form of data cleansing                                                                                                                                                                                                                               |

## Summary

Data validation is a cleaning feature to check the accuracy and quality of data before adding or importing it. Data warehousing specialists make sure that data is available, secure, and backed up to prevent loss. They do this by developing processes and procedures to effectively store and organize data. If a dataset contains nulls, this is an indication that those values do not exist in the dataset. Field length determines how many characters can be keyed into a spreadsheet field.
